## 5. Why it became inadmissible
CRE-S7 widened Conway enactment to key 16 (minPoolCost 170,000,000 -> 75,000,000). Because
minPoolCost is FINGERPRINTED, replaying identical blocks now yields different durable authority
bytes, so STORE_SEMANTICS_VERSION was bumped 2 -> 3. A store whose 304->305 boundary was crossed
under the OLD enactment rules cannot be used to prove the NEW ones — it would be a store with
one semantics and a binary with another, which is precisely the P4 (e1de7a2e) failure this
marker exists to prevent. There is deliberately no stamp path and no override.
